# 移除牛来、恢复轻盈项链

使用内置 image_gen，源图 study-source-plate-v12.webp。

最终提示词规格：仅做两处编辑。移除桌上橙色牛来和其投影，用匹配的木墙、桌面填补，不添加替代物。将书上的厚带状项链改为远景约一像素宽的细银链，用约十个较短直线段近似自然垂落与松弛弧线，表现轻盈细链而非厚腰带；圆牌为规则十边形近似圆形，形状与旁边球仪的分段圆环相呼应，使用正常平面圆片的透视，保留低清小王子头像与暗边。保持刚性书本、笔直书沿和平面书脊。早期 Source 低面数、低分辨率漫反射、粗糙烘焙灯光，不使用现代珠宝摄影反射。不改变其余物品和相机。

资产：study-no-bull-thin-necklace-v1.png；网页使用 study-source-plate-v13.webp / study-source-open-v13.webp。旧版本保留。

export-no-bull-thin-necklace.mjs 仅替换书本和原牛来两个区域，验证区域外像素不变。网页已删除牛来热点、描边、互动函数和贴图引用。
