# 风铃：硬分面版本

使用内置 image_gen，以既有风铃局部截图作为编辑目标。

最终提示词规格：保持画布比例、物体位置和底座尺寸，将铃铛改成由约六个平坦梯形面组成的低多边形截锥铃罩，各面使用明显不同的暗黄铜明度，去除连续渐变高光、圆润鼓面和反射。支架为方截面直杆和直角弯头，挂钩只有三段直线；铃舌为小木块。纸条是平直四边形，配低清红色块状图案。木底座为锐利长方体，粗糙木纹。匹配廉价早期 Source/Half-Life 2 资产的平面着色和硬烘焙光，不添加文字，不改变相机与整体比例。

原始编辑输出：windchime-source-faceted-v2.png。
实际场景：study-source-plate-v17.webp / study-source-open-v17.webp。
