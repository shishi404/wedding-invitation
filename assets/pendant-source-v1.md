# 书上的小王子吊坠

使用内置 image_gen 编辑原书房，按用户提供的小王子圆牌项链照片生成；原版本保留。

最终提示词规格：仅在原 1536×1024 书房图台灯右侧的书堆上添加一条小号银色圆牌项链。圆牌面朝上放在上层书前缘，直径约 22–25 像素，深色边框、浅银底色与黑色小王子头像。细银色链条松散不对称地搭在书面上，一部分自然绕过前侧书沿，受重力垂落在两本书的书脊前，不是僵硬 V 形，也不悬浮。匹配 2004 Source / Half-Life 2 / 早期 Garry's Mod 的简单几何、低分辨率漫反射贴图、粗糙烘焙光和接触阴影。金属受到左侧台灯的暖色照明，无现代珠宝摄影反射、无发光、无额外文字或 UI。除项链区域外保留原场景的布局与物品。

资产：
- pendant-source-scene-edit-v1.png：生成的编辑原图。
- pendant-source-region-v1.svg：仅项链及接触区域的裁切层。
- study-source-plate-v8.png / .webp：合成后的书房。
- study-source-open-v8.png / .webp：对应的抽屉打开版本。

export-pendant-scenes.mjs 仅将项链区域合成到原 v7 PNG，逐像素验证该区域外没有变化。此次只增加场景摆设，不变更互动规则。
