# 领取纪念品后的桌面背景

领取动作仍只来自便签。study-state 广播所选纪念品；场景同步覆盖该物品实物、隐藏描边、隐藏并禁用热点。旧的点击处理及 study-object 事件也拒绝打开已领取的物品。物品栏调用独立详情函数，保留铃铛和八音盒音频功能。剩余两件仍可在桌面查看。

背景补片：
- musicbox-cleared-v1.webp：原 v17 版本对应区域，恢复八音盒下方原桌面及阴影。
- windchime-cleared-v1.webp：原 v14 版本对应区域，恢复原木墙和桌面。
- pendant-cleared-v1.webp：修复移除项链后的书面。源图 books-without-pendant-source-v1.png。

吊坠背景使用内置 image_gen 生成。最终提示词规格：以当前两本书局部为目标、最早没有项链的两本书为纹理与形状参考，去掉全部链条与圆牌，补回绿色上层书和棕色下层书的平面纹理，保持刚性书本轮廓、笔直封面边缘、透视、原灯光和低清 Source 纹理。不添加任何物体、银色痕迹、线条或文字。

export-keepsake-removals.mjs 导出三个小型无损 WebP 补片，不覆盖原场景与旧版本，页面预载它们以避免首次领取时延迟显示。抽屉开关和其他状态刷新后保持已领取物品隐藏。

验证：320、390、1440 像素视口；三种选择的实物/轮廓/热点同步消失；事件无法绕过；物品栏仍可查看与播放音频；未领取的纪念品仍可交互；隐藏风铃不触发悬浮铃声；实际取得钥匙和打开抽屉后隐藏状态保持。
