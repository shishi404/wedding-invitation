# 调查检定窗口

根据用户提供的《博德之门3》检定界面参考，以原生 SVG 和 CSS 绘制新的金属边框、结绳分隔纹路、暗紫色磨损背景及纪念品卡片。没有将截图或视频 UI 放进网页。

- 显示“调查”、当前检定类型和“检定数值”。普通检定显示当前属性，极难检定显示当前属性五分之一（向下取整），与实际判定共用 checkThreshold。
- 按用户确认，属性仍为基础 55；对应纪念品提供 +5 后为 60。
- 只有选择的纪念品与本次属性对应时显示 +5、物品图及名称；其他情况显示 +0 与无对应纪念品。
- 极难检定标题显示“极难力量检定”，中央检定数值为 11（力量 55）或 12（力量 60），点数不高于该值即通过。
- 保留原双十面骰的模型和材质，嵌入模式中放大显示；原独立骰子页面的取景保持不变。
- 打开窗口只展示静止骰子。点击骰子区域（或键盘激活同一按钮）后才发起一次投掷。结果展示 3 秒后应用到剧情。
- 点数显示在当前属性下方、骰子上方，字号小于属性。落定后标题改为成功／失败／大成功／大失败；成功使用金色、失败使用红色，属性与点数同步跳动一次。下一次检定恢复初始状态。
- 每次点击掷骰随机播放 dice1.ogg 或 dice2.ogg 一次，使用独立音效通道，不影响背景音乐；重复点击不会重复投掷或播放。
- 检定未点击时不会启动超时随机备用流程；没有 WebGL 或 iframe 无法载入时，仍可点击后获得正常 D100 结果。

源文件：check.css、check-ornate-frame.svg、study.js、dice.js、dice.html、dice.css。构建产物由 build-browser.mjs 生成。

验证：320×568、390×844、1440×1000；三个属性与纪念品、+0/+5、极难目标、四类结果、钥匙保底、重复检定复用同一 iframe、避免重复投掷、HTTP 与 file://、没有 WebGL 和 iframe 失效时的备用流程。
