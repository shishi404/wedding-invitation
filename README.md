# 婚礼请柬空白模板

手机优先的静态网页，无需安装依赖。包含拆信交互、滚动渐显及减少动态效果偏好适配。未使用外部字体、追踪或第三方图片。

## 预览与修改

直接双击 index.html 即可预览。修改 data.js 中的姓名、时间、地点、故事等字段。照片上传到仓库后，把相对路径填写到 photo 中。

## 发布到 GitHub Pages

1. 新建仓库，将 index.html、data.js 放在仓库根目录。
2. 进入 Settings → Pages。
3. Source 选择 Deploy from a branch，分支 main，目录 / (root)，保存。
4. 等待部署后使用 Pages 显示的网址，在手机和微信内实际打开测试。

这是静态请柬，不收集宾客回复。链接可被继续转发，小范围分享不等于访问限制。发布的数据应视为公开内容。

微信分享时的卡片标题和缩略图取决于微信环境，本模板不保证自定义分享卡片。

婚礼后可在 Settings → Pages 中选择 Unpublish site 停用网站。停用网站不会删除仓库中保存的数据与历史提交。
